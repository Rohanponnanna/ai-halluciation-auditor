# 🔍 AI Hallucination Risk Auditor

**Corporate AI Integrity Governance System (CAIGS) | India Business Context**

Test ChatGPT, Claude, and Gemini outputs against verified Indian business
regulations across Finance, HR, Legal, Marketing, and Operations domains.

## Features
- 50 verified India-specific business prompts (expandable to 500)
- Multi-LLM comparison: GPT-4o, Claude, Gemini
- Composite hallucination scoring (semantic + numerical + ROUGE-L)
- CAIGS A–D governance grade with financial risk estimates
- CSV/Excel export for research use

## Usage
Enter your API key(s) → Select domains → Run audit → Get CAIGS score
